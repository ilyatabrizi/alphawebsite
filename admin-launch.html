تأیید خودکار با پیامک بانک خاموش

راه اصلی تأیید: گوشی‌ای که پیامک‌های بانک به آن می‌رسد، هر پیامک را به این نشانی می‌فرستد. واریزی که دقیقاً مبلغ یک فاکتور باز باشد (مثلاً ۱٬۸۸۸٬۴۳۷)، همان لحظه آن را پرداخت‌شده می‌کند؛ دست شما لازم نیست. فقط اگر پیامک یک «واریز کردم» تا ۱۰ دقیقه نرسد، دکمه «✅ رسید» و «❌ نرسیده» در تلگرام می‌آید (و اگر گوشی ۷ روز چیزی نفرستاده باشد، همان لحظه). مانده حساب ذخیره نمی‌شود و پیامک‌های برداشت و خرید دور ریخته می‌شوند.

راه‌اندازی روی اندروید
  1. برنامه رایگان و متن‌باز SMS to URL Forwarder را از F-Droid یا صفحه GitHub آن نصب کنید (در گوگل‌پلی نیست): github.com/bogkonstantin/android_income_sms_gateway_webhook
  2. دکمه + را بزنید. در Sender شماره یا نام فرستنده پیامک‌های بانک را بنویسید (یا * برای همه).
  3. در URL نشانی بالا را بچسبانید؛ قالب پیام پیش‌فرض (from و text) را دست نزنید. ذخیره کنید و اجازه خواندن پیامک را بدهید.
  4. برنامه را از «بهینه‌سازی باتری» بیرون بیاورید تا همیشه کار کند. هر پیامکی که به بانک ربط ندارد، روی سرور دور ریخته می‌شود.
راه‌اندازی روی آیفون
  1. برنامه Shortcuts ← Automation ← New Automation ← Message.
  2. فرستنده را بانک بگذارید (یا Message Contains: «واریز») و Run Immediately را انتخاب کنید.
  3. اکشن Get Contents of URL: نشانی بالا، Method: POST، Request Body: JSON با فیلد text = Shortcut Input.

ربات بله: خبر و تأیید هر واریز توکن لازم است

هر «واریز کردم» مشتری (با شماره پیگیری و مبلغ دقیق) با دو دکمه «✅ رسید» و «❌ نرسیده» به بله شما می‌آید؛ هر کدام یک بار دیگر می‌پرسد (مثلاً «بله، ۱٬۸۸۸٬۴۳۷ تومان رسید») تا با یک لمس اشتباه سایتی فعال نشود. پرداخت‌های تأییدشده و تیکت‌های تازه هم همین‌جا می‌آید. بله داخلی است و رله نمی‌خواهد. تا توکن بله را نگذارید، خبرها مثل قبل به تلگرام می‌رود.

  1. در بله، @botfather را باز کنید و /newbot را بفرستید.
  2. یک نام (مثلاً «آلفا وب‌سایت») و یک نام کاربری که به bot ختم شود (مثلاً alphawebsite_bot) بدهید.
  3. توکنی را که بله می‌دهد کپی کنید و این‌جا بچسبانید؛ جای دیگری نفرستید.
